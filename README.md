# 选股有据

自然语言选股与策略解释工作台。同花顺 AI 产品经理笔试《自然语言智能选股与策略解释器》的可运行原型。

> **状态说明：产品已部署，公网真实主链路验证通过。** [打开选股有据](https://stock-lens-production-9620.up.railway.app)，评审账号通过笔试私有附件提供。[源码仓库](https://github.com/Ovaltine911/stock-lens)。DeepSeek真实解析、iFinD12股真实快照、筛选/证据/保存恢复已在公网验证。79项单元/接口、6项本地浏览器测试和完整设计检查通过。已修正用户反馈的错误横幅误显示，见[修复记录](docs/ERROR_BANNER_FIX.md)。见[公网验证记录](docs/PRODUCTION_VALIDATION.md)。新环境未配置凭证时明确使用合成演示与规则解析，不冒充真实行情或大模型。

## 目标用户与产品选择

面向有基本投资研究意图、但不熟悉筛选指标和语法的个人投资者。解决“说得出偏好，不能确认系统究竟按什么筛选”的问题，而不是预测涨跌。

产品核心：将模糊意图转换成可编辑的条件草稿，由用户确认；程序在同一份有来源的数据快照上筛选，并逐项解释通过、不通过和无法确认的原因。

**当前目标用户是假设，尚未做真实用户访谈；不宣称有提升效率、满意度或收益的实测结果。** 完整产品取舍与指标定义见 [产品说明](docs/PRODUCT.md)。

## 本地启动

需要 Node.js 20 或更高版本。生产运行无第三方依赖。

```bash
npm ci
cp config.example .env
npm start
```

打开 `http://127.0.0.1:4173`。首次体验选择“演示数据”，点击加载后输入：

- `市盈率小于20`：明确条件解析。
- `经营改善、估值合理、走势相对稳定`：生成五条草稿，确认解释后筛选。
- `市盈率小于10且市盈率大于30`：检验条件冲突。

每一条条件支持修改指标、比较符和阈值。修改后必须重新确认；保持原快照即可计算结果差异。

## 已实现

- 结构化条件编辑与显式确认，最多 16 条，仅支持条件全部满足。
- 有限自然语言规则解析，以及 OpenAI-compatible 模型适配接口。
- 模糊词的可编辑建议、澄清提示与不支持条件的显式呈现。
- 确定性筛选、严格及包含边界冲突检查。
- 每条件保留实际值、字段名、来源、数据时点、单位、口径和异常说明。
- 三值结论：通过、不通过、未知。单项明确不满足优先于整体未知，但所有单项状态保留。
- 同快照条件修改前后差异；候选横向比较。
- 当前浏览器本地保存、历史恢复查看、当前结果 JSON 导出。
- 来源切换与文本修改后失效旧结果，防止晚到请求覆盖新状态。
- 桌面和手机窄屏布局、系统浅深色、键盘打开证据。

## AI、筛选引擎、数据工具的职责

| 模块 | 职责 | 不允许做什么 |
| --- | --- | --- |
| AI/意图解析 | 理解表达、生成草稿、标明模糊或不支持的需求 | 编数据、决定买卖、自动修改用户明确阈值 |
| 用户确认 | 审查指标/口径/阈值，接受或编辑草稿 | 不把系统建议阈值当客观投资结论 |
| 筛选引擎 | 数值比较、冲突检查、三值汇总、同快照差异 | 自行猜补缺失字段、以模型语言替代计算 |
| 数据适配器 | 从明确选择的来源获取字段，校验和记录来源/时间/口径 | 调用失败时偷偷退成演示数据 |

模型提示词和版本在 `lib/llm.mjs`。未配置模型时界面明确显示“规则解析模式，未调用大模型”；配置后的模型请求失败不会静默返回规则成功。

## 数据来源与范围

详见 [数据说明](docs/DATA_SOURCES.md)。

| 模式 | 当前覆盖 | 重要限制 |
| --- | --- | --- |
| 合成演示 | 12 个虚构名称与代码，多种通过/失败/缺失案例 | 不是实际股票，不得用来做投资判断 |
| 公开来源 | 固定 12 家 A 股观察样本，前复权日线派生 20 日价格变化、年化波动率 | 非全市场；PE口径不明不采用；PB/市值缺数据时点则未知；财务未接入 |
| 扶摇 | 估值与日线适配代码 | 需要服务端密钥；未完成有权限账号的真实调用验证 |
| iFinD | 独立服务端客户端已接入；12股的PE TTM、PB MRQ、报告期加权ROE实测可核验 | 固定日期快照，财务2026-09-30、估值2026-11-06，非实时行情；累计同比及其他未核验字段保持未知；见[接入说明](docs/IFIND_DATA.md) |

真实观察池固定而非按结果挑选，见 `lib/data.mjs` 的 `RESEARCH_POOL`；行业标签是人工元信息，不用于行业筛选。实时可用字段以实际响应和证据状态为准。公开接口不构成可用性保证或数据再分发授权，部署前需核对服务条款。

数据时效保护当前以 7 个自然日为日线/快照过期阈值，长假可能误伤；下一步应改为交易日历。前复权价格变化不等于含费用、税费和分红再投资的策略收益。

### 真实模式使用

有权限的iFinD账户在服务端设置 `IFIND_API_KEY`，前端显式选择“iFinD · 授权固定日期快照”。例如输入 `市盈率大于0且市盈率不高于25且净资产收益率大于10%`，解析并确认后，在固定样本池中核验每家公司是否满足条件。一次加载约6次工具查询，可能消耗账户额度；不支持或无法核实的字段不补数。

DeepSeek本机配置可使用 `node scripts/setup-model.mjs` 启动仅本机配置入口；生产通过 `LLM_API_KEY`、`LLM_MODEL`、`LLM_BASE_URL=https://api.deepseek.com` 设置。`.local/`私有配置不进入仓库和Docker镜像。**受限金融数据不得未经许可公开展示或提供下载；上线前需确认账户权益，必要时设置评审访问限制。**

## 环境变量

| 名称 | 用途 |
| --- | --- |
| `HOST` | 本地默认 `127.0.0.1`；容器监听 `0.0.0.0` |
| `PORT` | 默认 4173，部署时使用平台分配端口 |
| `LLM_API_KEY` | 服务端模型凭证，不可传给前端 |
| `LLM_BASE_URL` | OpenAI-compatible 服务地址，默认官方 v1 地址 |
| `LLM_MODEL` | 部署者实际有权限使用的模型名，与 key 一起配置后启用 |
| `FUYAO_API_KEY` | 扶摇数据服务凭证 |
| `IFIND_API_KEY` | iFinD 服务端凭证，生产部署使用秘密环境变量 |
| `IFIND_CONFIG_PATH` | 本机可显式指定已有iFinD配置文件位置，不可把本机路径用于云端 |
| `PUBLIC_DATA_ENABLED` | 仅值为 `true` 时开放用户显式选择公开来源 |
| `APP_ORIGIN` | 正式产品完整 origin，用于跨站来源检查 |
| `REVIEW_USER` | 评审登录名，默认 reviewer |
| `REVIEW_PASSWORD` | 至少16字符的评审访问口令，仅通过秘密配置设置；生产使用模型或金融凭证时必须配置，防止匿名消耗额度 |

生产站点通过浏览器原生登录弹窗进入，须使用HTTPS。评审账号只随笔试私有附件交付，不放公开README、URL或GitHub。访问保护不等同取得金融数据再分发许可。Railway以 `/api/health` 检查实例是否启动，该接口只暴露配置状态而不含行情或凭证。

`config.example` 不包含真实密钥；`.env` 被 Git 忽略。iFinD 密钥与扶摇密钥不是同一种凭证，不可混用。不要提交技能的 `config/mcp_config.json`，不要把整个工作区直接压缩上传。

见 [部署及提交清单](docs/DEPLOYMENT.md)。可使用支持 Node.js 长驻进程的平台或 Docker。当前服务使用进程内快照缓存，**不适合直接部署为无共享状态的多实例/短生命周期 Serverless 函数**。已部署实例从冻结代码提交构建，不与GitHub后续文档更新自动联动；代码修改后需显式重新部署并验收。

## 已知边界与未做事项

- 没有真实用户研究及线上效果实验，没有投资收益/准确率承诺。
- 不支持 OR/嵌套布尔表达式、行业成分、ST剔除、新闻筛选、任意财务期间和全市场覆盖。
- 规则解析是有限语法，不能视为通用语言理解；生成的任何草稿都需要用户检查确认。
- iFinD已核验报告期加权ROE；财务同比的累计/单季度口径尚不充分，真实字段保持未知，不能解释为不增长或亏损。
- 不做自动交易、买卖建议、仓位建议、涨跌预测、策略回测或后台监控调度。
- 本地记录只保存在当前浏览器，不是多用户数据库；服务快照缓存最多 100 份、有效期 30 分钟，重启后失效。
- 当前同源检查、速率限制和并发上限是原型防护，不替代生产账号鉴权、审计、限额和数据授权体系。
- 已有公网产品与远程源码仓库；仓库评审权限、候选人本人走查及数据展示权益须在提交前确认。Railway使用现有试用额度，需关注余额，不能保证永久免费。
