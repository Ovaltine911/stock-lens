# 选股有据

一句话描述研究条件，查看有来源的筛选结果。同花顺 AI 产品经理笔试《自然语言智能选股与策略解释器》的可运行原型，**非同花顺官方产品，不提供买卖建议**。

> **版本状态：V3已上线并通过公网真实浏览器验收。** [打开一句话选股](https://stock-lens-production-9620.up.railway.app)，使用私有附件中的评审账号；[GitHub公开源码](https://github.com/Ovaltine911/stock-lens)。运行提交`77ca4f3`，版本0.2.0。121项单元/接口、8项浏览器回归和完整设计检查通过；公网明确单提交、模糊单确认、真实自动取数筛选均通过。首次公网明确请求单次18.7秒，不作为P95承诺。见[V3验证记录](docs/V3_VALIDATION.md)。

## 为什么改版

旧版把选源、加载、解析、勾选和确认暴露给用户，更像调试工作台。用户明确要求简化流程，并参考同花顺的金融信息界面风格。V3 将主流程改为用户任务：**输入 → 筛选 → 核对证据**，供应商选择由后台负责。

- **明确条件**：输入 `市盈率大于0且市盈率不高于25且净资产收益率大于10%`，点击一次“开始筛选”，展示可编辑条件并自动取数、执行，不重复确认已明确的阈值。
- **模糊表达**：输入 `经营改善、估值合理、走势相对稳定`，展示 5 条建议和 3 条解释；检查或编辑后，只点一次“按这些条件筛选”，不逐项勾选。
- **结果之后**：核对通过/未通过/数据不足、逐字段证据、2–3 个候选横向对比；改阈值后点“更新结果”，在同一快照上比较；支持本浏览器保存、历史查看和当前结果导出。

以上V3交互已通过本机浏览器验收，已修复手机数据入口和冲突提示等联调问题。减少必要操作是设计取舍，**不是已测得的用户效率提升**。目标用户仍是假设，未做访谈、可用性研究或收益验证。详见 [产品说明](docs/PRODUCT.md)。

## 本地启动

需要 Node.js 20+；生产运行无第三方依赖。项目根目录执行（已有 `.env` 时不要覆盖）：

```bash
npm ci
cp config.example .env
npm start
```

打开 `http://127.0.0.1:4173`。

- 正常入口自动使用真实数据 `auto`，不要求用户选供应商或手动加载。
- 新环境未配置数据凭证时，自动模式明确报错；可通过**次级独立演示入口**体验合成数据，不会悄悄退成演示成功。
- 未配置模型时明确使用有限规则解析；配置模型后请求失败不会静默改成规则结果。
- 冲突示例：`市盈率小于10且市盈率大于30`。冲突、不支持要求和合规阻断均不得静默执行部分意图。

### 仅本机安全配置

```bash
node scripts/setup-model.mjs
# DeepSeek 配置入口：http://127.0.0.1:4174

node scripts/setup-fuyao.mjs
# 扶摇配置入口：http://127.0.0.1:4175
```

两个配置入口共用回环地址、Host/Origin、令牌、替换确认和私有文件保存保护，分别验证各自供应商。模型列表验证不等于推理成功；扶摇单只估值接口验证不等于全部数据权限已验证。配置操作会访问供应商，可能消耗额度，不是离线测试。

扶摇本机配置保存后，运行产品时需显式设置 `FUYAO_CONFIG_PATH=.local/fuyao.json`，或使用 `FUYAO_API_KEY`（环境密钥优先）；不会自动搜索本机凭证。本次工作区扶摇已安全保存并完成全 12 股本机验证，**云端尚未配置 `FUYAO_API_KEY`**。不要将 `.local/`、`.env` 或真实响应提交/打包。详见 [部署说明](docs/DEPLOYMENT.md)。

## 数据范围与真实验证

**固定 12 家 A 股观察样本，非全市场、非实时行情承诺。** 自动模式以扶摇为主；仅主源 PE/PB/ROE 缺失且已配置 iFinD 时做有限补充。供应商透明地展示在“数据与口径”和逐字段证据中，但不是正常流程中的选择题。

| V3 自动模式指标 | 本次真实 12 股覆盖 | 重要口径 |
| --- | --- | --- |
| PE TTM、PB MRQ、报告期加权 ROE | 各 12 `ok` | 估值元数据时点与财务报告期分别保留 |
| 20 日年化波动率、20 日价格变化 | 各 12 `ok` | 与交易日历对齐的 21 个前复权收盘价 |
| 年度营收同比 | 12 `ok` | 最近两个已披露完整年度原值计算 |
| 年度归母净利润同比 | 11 `ok`、1 `missing` | 非正基年等情况不可用常规增速替代 |
| 原营收/利润累计同比、总市值 | 各 12 `missing` | 不把年度值冒充季度/累计值，不猜市值单位 |

本机一次自动快照 **HTTP 200、1570ms、19 次主源请求**，复用测试 `CACHE_REUSE=true`；年度增长 + PE + 波动率五条件筛选为 **5 通过、7 未通过、0 整体未知**。某股票已明确失败时仍可能存在单项未知，证据不丢弃。以上不是 P95、全市场覆盖或云端性能承诺。

自动快照以交易日历确定最近交易日；年度使用响应中的最近已披露年度（例如 2025/2024，而非写死年份），估值时间单独显示，`fetchedAt` 不冒充行情日期。年度两年原始字段、分子分母和期间保留为证据；ROE 使用官方百分数值口径，不根据数值大小猜倍率。详见 [数据说明](docs/DATA_SOURCES.md) 和 [自动适配技术说明](docs/AUTO_DATA.md)。

## 职责与安全边界

| 模块 | 职责 |
| --- | --- |
| 模型 / 规则解析 | 生成目录内可编辑条件，保留明确阈值，指出新增假设和不支持要求；不编数据、不决定买卖 |
| 用户 | 模糊假设只确认一次；明确条件可直接提交，之后仍可检查和修改 |
| 确定性引擎 | 最多 16 条 AND 条件、冲突检查、三值汇总和同快照差异；未知不通过 |
| 自动数据适配 | 后台选源，逐字段校验来源、日期、单位和期间；失败明确报错，不退 demo |

自动取数缓存为**同进程 15 分钟，跨上海自然日失效，并发请求合并（singleflight）**；命中保留原 `snapshotId` 与真实数据日期。筛选用快照存储另有默认 30 分钟、最多 100 份的生命周期，重启失效。改条件不重新取数；失效后须重新查询，历史不能作为当前快照执行。这不是回测。

## 配置与部署

| 变量 | 用途 |
| --- | --- |
| `HOST` / `PORT` | 本机默认 `127.0.0.1:4173`；容器监听 `0.0.0.0` 并使用平台端口 |
| `LLM_API_KEY` / `LLM_MODEL` / `LLM_BASE_URL` | 服务端 OpenAI-compatible 模型配置 |
| `FUYAO_API_KEY` / `FUYAO_CONFIG_PATH` | 主源凭证或显式本机私有配置路径 |
| `IFIND_API_KEY` / `IFIND_CONFIG_PATH` | 有限备用凭证或显式私有配置路径，不与扶摇混用 |
| `PUBLIC_DATA_ENABLED` | 历史公开适配开关；不是 V3 正常入口的供应商选项 |
| `NODE_ENV` / `APP_ORIGIN` | 正式部署设 `production` 和实际 HTTPS origin |
| `REVIEW_USER` / `REVIEW_PASSWORD` | 评审访问保护；生产配置模型/金融凭证时，必须提供至少 16 字符口令 |

评审账号仅通过私有附件交付。生产安全检查同时覆盖环境密钥与显式金融配置路径，未正确配置访问保护会拒绝业务访问；健康检查只显示配置状态，不证明凭证有效或数据已可用。查询授权不等于公开再分发权。

使用单实例常驻 Node 或 Docker，不直接部署为无共享状态的多实例/短生命周期 Serverless。完整步骤及 V3 发布待办见 [部署说明](docs/DEPLOYMENT.md)。
