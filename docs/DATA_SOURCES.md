# 数据来源与真实性边界

## 1. V3 的正常入口是自动数据，不是供应商选择

用户输入研究条件后，服务端后台选择来源。供应商、日期和口径在“数据与口径”及逐字段证据中透明披露，但不要求用户先选源或手动加载。`auto` 为正常模式；`demo` 为用户显式进入的次级独立演示，真实失败绝不静默退demo。

**范围固定为12家A股观察样本，非全市场。** `lib/data.mjs` 的 `RESEARCH_POOL` 不按筛选结果临时挑选，行业标签是人工元信息，不代表支持行业筛选。

当前V3已完成本机自动数据验证，尚未部署。公网仍为V2 `a8462ee`，GitHub PUBLIC已推送V2；云端尚未配置扶摇。最新真实覆盖以 [V3验证记录](V3_VALIDATION.md) 为准，[V2公网验证（历史）](PRODUCTION_VALIDATION.md) 不代表V3云端已可用。

## 2. 本机全12股真实验证

主协调已用本机安全保存的扶摇凭证完成一次完整自动快照及缓存复用：

```text
AUTO_HTTP=200
AUTO_DURATION_MS=1570
AUTO_COUNT=12
AUTO_PROVIDERS=["同花顺扶摇金融数据 API"]
CACHE_REUSE=true
AUTO_SCREEN_HTTP=200
AUTO_SCREEN_COUNTS={"pass":5,"fail":7,"unknown":0,"total":12}
```

正常主源预算 **19请求**，此次主源已满足主要字段，无需iFinD。五条件为两个年度增长、`PE>0`、`PE≤25`、20日年化波动率`≤30%`。`unknown=0`只指股票整体结论：某公司已明确失败时，其他单项未知仍保留。

| 指标 | 本次真实覆盖 | 当前能力边界 |
| --- | --- | --- |
| `pe_ttm` / `pb_mrq` | 各12 `ok` | 明确TTM/MRQ；估值元数据时点单列 |
| `roe` | 12 `ok` | 报告期加权平均，不混用摊薄/年化 |
| `volatility_20d` / `return_20d` | 各12 `ok` | 日历对齐的21根前复权收盘价 |
| `revenue_yoy_annual` | 12 `ok` | 最近两个已披露完整年度营收原值计算 |
| `profit_yoy_annual` | 11 `ok`、1 `missing` | 最近两个完整年度归母利润；非正基年不计算常规增速 |
| `revenue_yoy` / `profit_yoy` | 各12 `missing` | 原报告期累计同比仍未核验，不以年度替代 |
| `market_cap` | 12 `missing` | 无明确字段与金额单位，不从行情倒推 |

1570ms是本机单次观测，**不是P95、全市场性能、云端结果或供应商稳定性保证**。不公开真实受限股票数值和原始响应。数据Worker早期探测范围及25项合成测试见 [AUTO_DATA.md](AUTO_DATA.md)；该文档阶段记录早于主协调完整12股验证，二者不应混为同一批请求。

## 3. 自动取数如何选择来源

实现为 `lib/auto-data.mjs`，服务端运行时读取 `FUYAO_API_KEY`；缺失时只读取显式 `FUYAO_CONFIG_PATH`，不搜索本机凭证。iFinD使用其自己的 `IFIND_API_KEY` / `IFIND_CONFIG_PATH`，两种凭证不能混用。

| 主源模块 | 12股正常请求数 | 取数内容 |
| --- | ---: | --- |
| 交易日历 | 1 | 最近100个自然日内的交易日 |
| 估值 | 2 | 10+2分组 |
| 前复权日线 | 2 | 10+2分组，`interval=1d&adjust=forward` |
| 年度利润表 | 2 | 10+2分组，最近两个完整年度 |
| 加权ROE | 12 | 单股财务指标 |
| **合计** | **19** | 不含有限备用，不自动重试 |

主源最多2个在途请求，每批最多10股。每请求12秒超时覆盖连接和正文，校验HTTP与业务 `code=0`，禁止重定向并限制响应体积。HTTP200不是金融数据有效的充分条件。

### iFinD只做有限补充

仅当某证券PE/PB/ROE在扶摇不可用且iFinD已显式配置时，才握手并按缺失字段/证券查询；不覆盖主源成功值，不拉取无关字段或无差别重跑全量。

- 主源主要字段齐全时，iFinD请求为零。
- 备用估值仍固定 **2026-11-06**，ROE仍固定报告期 **2026-09-30**，保留每字段真实来源与日期，不宣称实时或最新。
- 已有主源交易日历时，备用估值日期须与之匹配才接纳；日期不符不拼成“同日估值”。
- 日历失败、仅有备用时，快照只说明有限固定日期覆盖，不能声称已核验最近交易日。
- 局部坏数据标记missing/error并给warning；必要主模块全失败且无可用有限覆盖，或所有字段均不可核验时，明确返回安全错误，不创建空成功快照。

具体映射、错误预算与边界以 [AUTO_DATA.md](AUTO_DATA.md) 为准。`DATA_` / `FUYAO_` / `IFIND_` 错误不透传密钥、认证头或供应商自由文本。

## 4. 日期、年度和单位必须分别核对

### 不把所有数据统一贴同一天

- `asOf`：自动模式正常取成功核验的交易日历最近交易日；不是写死2026-11-06。休市日与交易日可能不同。
- `fetchedAt`：读取开始时点，不是行情日期或财务可获得日。
- PE/PB：保留 `data.timestamp` 的上海日期；这是响应上游元数据最大时点，不保证每字段同步。当前探测曾出现11月8日元数据与11月6日最近交易日的差异，不能擅自改贴。
- ROE：报告期末不是公告日。请求期与响应证券/报告必须匹配，不能猜测前期数值。
- 年度：响应的披露/修订时间不等于已证明首次披露时间；不能据此做无前视偏差回测。

### 年度同比需要两年原值证据

使用同供应商、同证券、相邻两个已披露完整年度，例如2025/2024，**年份随数据而不是固定模板**。营收取 `operating_income`，归母利润取 `parent_holder_net_profit`：

`年度同比百分数值 = (当年原值 / 基年原值 - 1) × 100`

`raw.records`保留两年白名单原始记录，包括证券、年度、报告类型、完整年末、披露/修订时点、币种、原币元数值；另附分子、分母、基年/当年及公式。基年≤0、年度不相邻、单位/币种冲突、金额缺失或未来披露日期等均不可用。

“经营改善”仅建议年度增长并让用户确认，不等于拐点。明确季度或累计同比不能偷换成年度；原 `revenue_yoy` / `profit_yoy` 仍missing，不能解释为不增长或亏损。

### ROE不按数值大小猜倍率

仅接受 `index_weighted_avg_roe`，按[扶摇官方财务指标口径](https://fuyao.aicubes.cn/docs/api-reference/financial-indicators/)直接使用百分数值。例如合成值0.125表示0.125%，不是12.5%。拒绝冲突单位、非数字、重复或错误字段，不采用扣非、摊薄、年化字段替代。

### 20日价格指标

21个前复权收盘价按 `Asia/Shanghai` 日期与交易日历最后21日完全对齐；拒绝重复/逆序、缺日、非正/非有限价格及陈旧末日，不通过删除坏值偷偷拉长窗口。

- 年化波动率：20个对数收益率样本标准差 ×√252×100，样本方差分母19。
- 20日价格变化：`(末价/首价−1)×100`。

保存21个原始日期和收盘价作证据；价格变化不是含税费、交易费或分红再投资的策略收益。单位与期间统一取自 `lib/catalog.mjs`。

## 5. 缓存与证据状态

自动快照由服务端缓存**15分钟，同进程singleflight，跨上海自然日失效**。命中保留源日期、`snapshotId`，返回 `cached` / `cacheAgeSeconds`；不以缓存读取时刻把数据“刷新”。筛选用快照存储另有默认30分钟、最多100份，重启失效。改阈值只重算原快照，不重复取数；缓存不是历史数据仓库。

字段状态为 `ok`、`missing`、`stale` 或 `error`。只有有限数值、来源/字段/有效日期齐全、单位/期间匹配且status为ok才参与比较。缺失、错误、过期、口径不明均不通过。整体失败优先于未知，但不删除单项未知证据。

## 6. 演示与历史适配的边界

| 模式 | 定位 | 不应误读为 |
| --- | --- | --- |
| `demo` | 12家虚构名称/代码；历史模拟 `asOf=2024-12-31T00:00:00.000Z`，读取时间单独记录 | 真实公司、真实报价或数据失败后的默认成功 |
| `public` | 保留的东方财富公开适配，仅 `PUBLIC_DATA_ENABLED=true` 时可调用 | V3正常入口的供应商选项或完整财务源 |
| `fuyao` | 旧的直接估值/日线适配，仍在后端兼容 | 新 `auto` 的日历/年度/ROE完整聚合能力 |
| `ifind` | 旧独立固定日期适配已在V2验证；V3可按字段有限备用 | 动态最新财务或全指标自动覆盖 |

历史公开探测中，PE不能核验为TTM；PB/市值虽有数值，但 `f124=0` 无法提供可信时点；公开财务缺失，因此不拿这些字段假装有效。旧公开/直接扶摇适配的7自然日时效规则不代表V3自动模式：auto已使用交易日历核验价格窗口。iFinD独立接口细节见 [字段说明](IFIND_DATA.md) 与 [安装授权记录](IFIND_INSTALL.md)。

供应商文档：[扶摇快速开始](https://fuyao.aicubes.cn/docs/quickstart/)、[估值](https://fuyao.aicubes.cn/docs/api-reference/valuations/)、[行情](https://fuyao.aicubes.cn/docs/api-reference/prices/)、[财务报表](https://fuyao.aicubes.cn/docs/api-reference/financials/)。文档示例值只说明结构，绝不作为真实样本。
