# 测试与验证说明

## 1. 如何理解本记录

本项目区分四件事：**测试代码存在、某次运行通过、真实外部服务可用、真实用户能完成任务**。它们不能互相替代。

本文以2026-11-08[公网验证](PRODUCTION_VALIDATION.md)和[本机验证](LIVE_VALIDATION.md)为运行证据，并核对现有测试文件与脚本。文档 Worker 本次未重新运行全量测试或新增真实服务请求；若提交前代码继续改动，应对冻结版本重跑并记录输出。

## 2. 可复现命令

需要 Node.js 20 或以上，在项目根目录执行：

```bash
npm ci
npm test
npx playwright install chromium
npm run test:e2e
```

`npm ci` 与 Chromium 安装可能下载依赖。测试本身使用合成数据、mock 或本机随机端口，不需要真实模型/数据密钥。不要为了运行普通回归去开启收费接口。

按模块定位：

```bash
node --test tests/engine.test.mjs tests/intent.test.mjs
node --test tests/data.test.mjs
node --test tests/llm.test.mjs
node --test tests/setup.test.mjs tests/server.test.mjs
node --test tests/ifind.test.mjs
```

浏览器测试自行创建随机端口服务，不依赖本机 4173 的运行实例；`env: {}` 隔离真实服务配置。截图默认写入 `artifacts/`，也可由 `PICODE_ARTIFACT_DIR` 指定。提交截图前仍须确认没有真实授权数据或凭证，不能把任意整个 artifacts 目录公开上传。

建议最终保留：运行时间、提交标识、Node/浏览器版本、命令、退出码、测试数量和失败摘要；本次文档没有编造尚未生成的最终记录。

## 4. 真实服务验证：与 mock 分开记录

### DeepSeek

候选人通过仅本机开放的配置入口完成配置。模型列表验证不等于推理成功；随后产品 `/api/interpret` 完成真实推理。`intent-v1.0` 首次 HTTP 200、9271ms，但摘要数量与无依据不支持项错误，不能当语义验收通过。v1.1 改为 **summary 从 `conditions.length` 计数，不支持项必须连续逐字锚定用户原文**，三个真实输入复测如下：

| 输入 | HTTP / 模式 | 条件数 | 不支持项 | 单次耗时 |
| --- | --- | --- | --- | --- |
| 经营改善、估值合理、走势相对稳定 | 200 / llm | 5 | 空 | 10070ms |
| 市盈率小于20且股息率大于5% | 200 / llm | 1 | `股息率大于5%` | 3361ms |
| 市盈率小于20 | 200 / llm | 1 | 空 | 3575ms |

这些是有限点检，不是语义通过率、P95 延迟或可用性 SLA；温度为 0 也不能免除重复验证。不要把真实请求纳入每次自动回归，以免无意消费额度。

### 数据来源

| 来源 | 本轮真实证据 | 必须保留的限制 |
| --- | --- | --- |
| 东方财富公开源 | quote 与日线接口曾 HTTP 200、`rc=0`；日线可派生 20 日价格变化和年化波动率 | PE 口径无法核验为 TTM；PB/市值时间 `f124=0` 不可用；财务缺失；不是完整 12 股长期可用承诺 |
| 扶摇 | 无凭证探测 HTTP 200、业务码 `2001` | 这是业务失败，不是取数成功；未完成有权益账号验证 |
| iFinD 官方技能 | `listTools('stock')` HTTP 200，返回 10 工具 | 仅工具列表成功不能证明财务取数、额度或再分发权 |
| iFinD 正式产品网页 API | 完整 12 股、3 组财务+估值共 6 次工具请求成功；快照 HTTP 200、25757ms；PE TTM/PB MRQ/ROE 各 12 项 `ok`，其余各 12 项 `missing`；随后 PE/ROE 筛选 HTTP 200，6 通过/6 排除/0 未知 | 固定估值日 2026-11-06、报告期 2026-09-30，非实时、非公告日；同比累计口径未确认；0 未知仅对本次条件成立；公网与再分发权仍未验收 |

原始真实数据不应成为公共 fixture；公开提交保留必要的结构、状态与脱敏结论。若后续复测，要先确认账号授权、请求预算和输出位置，不能因有脚本就自动重跑。数据说明与准确探测边界见 [DATA_SOURCES.md](DATA_SOURCES.md)、[IFIND_INSTALL.md](IFIND_INSTALL.md)、[IFIND_DATA.md](IFIND_DATA.md)。
