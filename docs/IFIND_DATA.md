# iFinD 授权数据适配与核验记录

## 结论与最新证据（2026-11-08）

本模块对接**同花顺 iFinD 官方 MCP**，不是 Fuyao API，也不调用 PiCode 内部模型或凭证。Node 20 原生 `fetch` 实现，使用固定日期、12 家有限观察样本；不是实时行情服务、全市场荐股或回测系统。

**已接入正式产品网页 API，并完成本机完整 12 股快照与筛选验证。** 最新事实以 [LIVE_VALIDATION.md](LIVE_VALIDATION.md) 为准，不再将早期两股探测当作当前集成上限：

| 项目 | 实际结果 |
| --- | --- |
| 快照 | HTTP 200；单次耗时 25757ms；12 股 |
| 工具请求 | 3 组 × 4 股，每组财务+估值，共 6 次 `tools/call` 成功 |
| 可用指标 | `pe_ttm`、`pb_mrq`、`roe` 各 12 项 `ok` |
| 缺失指标 | `revenue_yoy`、`profit_yoy`、`volatility_20d`、`return_20d`、`market_cap` 各 12 项 `missing` |
| 固定日期 | 估值交易日 2026-11-06；财务报告期 2026-09-30 |
| 筛选 | HTTP 200；PE TTM > 0、PE TTM ≤ 25、报告期加权 ROE > 10%；6 通过、6 排除、0 未知 |

0 未知仅对这组 PE/ROE 条件成立，不代表所有指标有值；结果不是推荐或收益验证。单次耗时不是平均值/P95，也不证明其他账号、长期额度或公网环境可用。本页不包含真实证券指标值、密钥或完整远程响应。

## 协议、字段与日期

已观察到的真实结构为 JSON-RPC `result.content[].text` 内嵌 JSON：

```text
{code:1, msg:"success", subCode:null, subMsg:null,
 data:{answer:<Markdown表>, indicators_params:{<字段>:<参数对象>}}}
```

成功码是 **1**，不能套用 Fuyao 的 0。`isError`、JSON-RPC/业务错误、不可识别表格或证券错配会失败，不猜测另一套 schema。真实观测为 HTTP JSON；SSE 解析仅有合成测试覆盖。

| 应用指标 | 接纳的精确源字段 | 单位 / 日期依据 | 最新状态 |
| --- | --- | --- | --- |
| `pe_ttm` | `市盈率(PE,TTM)` | 比率展示“倍”；源行日期或该指标交易日期须为 2026-11-06 | 12 `ok` |
| `pb_mrq` | `市净率（PB，MRQ）` | 同上；不接纳没有 MRQ 的泛化 PB | 12 `ok` |
| `roe` | `净资产收益率ROE(加权,公布值)（单位：%）` | 百分点，不乘 100；源报告期须为 2026-09-30 | 12 `ok` |
| `revenue_yoy` | 返回过 `营业收入(同比增长率)（单位：%）` | 表头/参数未明确累计还是单季；请求问句明确不等于源口径已证实 | 12 `missing` |
| `profit_yoy` | 返回过 `归属母公司股东的净利润(同比增长率)（单位：%）` | 同上；不能用普通净利润替代归母 | 12 `missing` |
| `volatility_20d`、`return_20d`、`market_cap` | 未接入 | 不推测或拼凑 | 各 12 `missing` |

- 日期取自源响应，不取自请求问句、抓取时间或当前时钟。“最新”仅在可核验源日期等于目标日期时可用；无源日期、日期冲突、无效/未来日期或其他报告期均保守设为 `value:null,status:'missing',asOf:null`。
- ROE `period:'报告期'`、PE `period:'TTM'`、PB `period:'MRQ'` 与目录一致；具体日期另放 `asOf`、`note` 与最小 `raw`。
- 财务日期 **2026-09-30 是报告期末日，不是公告发布日期、可获得日或回测时点**，不声称当日已经可得。估值日 **2026-11-06** 同样固定，不随运行日自动变成实时行情。
- 快照 `asOf` 为有效字段日期最大值，不暗示所有字段同步；`fetchedAt` 只是本次采集时间。固定历史快照不套用“7 日内就是实时”的解释。
- `raw` 只保留 `{code,field,cell,date,parameter,parameterValue}`，不含整表、上游自然语言、认证头或 session。`sourceUrl` 指向官方 MCP 站点，不伪装成单元格公告原文链接；`note` 说明工具与查询参数。

服务端显式配置任一项：

| 配置 | 用途 |
| --- | --- |
| `IFIND_API_KEY` | 部署平台 Secret 注入的 iFinD MCP 用户密钥；优先于文件配置 |
| `IFIND_CONFIG_PATH` | 受保护 JSON 文件路径，加载时读取 `auth_token`；不默认搜索、不自动借用工作区配置 |

`ifindConfigured` 只表示配置存在，不证明认证/额度/取数成功。本机验证使用用户授权的显式配置；部署不能硬编码或公开本机路径，也不能把配置文件复制到镜像、仓库或前端。只输出安全错误码和中文消息，不暴露上游原始错误。

## 请求预算与错误边界

- 正常完整快照：6 次工具请求 + 初始化/通知，共 8 次 HTTP；没有主动 `tools/list`，没有自动重试。
- 全模块 FIFO：同一 Node 进程 HTTP 并发 ≤1、开始间隔 ≥600ms。多实例须另做共享配额控制，进程内队列不是账户全局限流。
- 单 HTTP 请求连同响应体 30 秒超时；响应上限 1MiB；拒绝重定向以免认证信息跨主机；校验 JSON/SSE、session/RPC ID、业务码、表头、单位、数值及证券代码。
- HTTP 401/403 → `IFIND_AUTH`；402/429 → `IFIND_QUOTA`，停止剩余请求，不自动升级。其他协议/业务错误使加载失败，不返回“空成功”。
- 表结构正常但部分字段/证券缺失则保留 `missing`；全部没有已核验字段则 `IFIND_DATA_UNAVAILABLE`。失败不偷偷换成 demo/public。
- 自然语言取数未来可能变化表头、口径或日期表达；本轮 12 股成功不保证后续请求成功。

```sh

```

最新集成后 `npm test` **75/75**、`npm run test:e2e` **5/5**，均 0 失败，见 [TESTING.md](TESTING.md)。这些是合成/mock/依赖注入测试，不消费真实接口额度，不与本页 live 观测混记。iFinD 用例覆盖协议、字段/单位/报告期、缺失、认证/额度错误、脱敏、超时、限速和完整合成快照。

[现有官方探测脚本](../scripts/probe-ifind.mjs) 无参数只打印用法，不联网；真实运行需显式 `--official` 指向已安装官方技能目录，可用 `--precise`，或用 `--financial-only` / `--valuation-only` 限制为一次工具查询。正常为两次查询、每次最多两股三指标，**不是完整产品 API 全量探测命令**；不要未经授权自动重跑。

探测仅输出结构与白名单元数据，隐藏上游文本和数值。只有 `IFIND_PROBE_SAVE_RAW=true` 且提供 `PICODE_ARTIFACT_DIR` 才保存到外部产物目录的 `ifind-private` 子目录（0700/0600），不能放入仓库或公共 fixture。
