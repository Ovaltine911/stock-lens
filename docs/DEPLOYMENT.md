## 2. 部署形态：选择单实例常驻 Node

当前 `server.mjs` 同时提供静态页面与 API，数据快照存于**单个 Node 进程的内存**，最多 100 份，默认 30 分钟失效。浏览器持有快照 ID，后续 `/api/screen` 必须回到持有该快照的进程。

适合：

- 支持常驻 Node.js 20+、环境秘密、出站 HTTPS 与自定义端口的平台，初期固定一个实例。
- 单实例 Docker，外部入口由平台或反向代理终止 HTTPS。

不适合直接使用：

- **GitHub Pages 等纯静态托管**：不能运行 Node API、保护模型密钥或维护服务端快照。
- 无共享状态的多副本、短生命周期 Serverless：后续请求可能找不到快照。会话粘滞也不能解决重启丢失；若未来扩容，需要共享快照存储和全局额度控制。

服务重启会使未保存快照失效；本地历史仍可查看，但不能冒充当前服务器快照重新执行。当前没有账户数据库、持久化策略库或生产级审计。

## 3. 本地启动与模型配置

### 基础启动

在项目根目录执行：

```bash
npm ci
cp config.example .env
npm start
```

打开 `http://127.0.0.1:4173`。先用“演示数据”验收闭环；它是显式虚构样本，不是行情。`.env` 仅用于本机配置，不提交仓库。复制前如已有本机配置，请先自行确认，避免覆盖。

### 可选：仅本机 DeepSeek 配置入口

另开终端：

```bash
node scripts/setup-model.mjs
```

打开 `http://127.0.0.1:4174`，在本机页面输入自己的有效凭证。配置工具先验证官方模型列表，不会因为点击保存就完成一次推理测试；实际推理须另行受控验收。

- 入口只绑定回环地址，具有 Host/Origin 与令牌检查；不得通过隧道、反向代理或公网暴露配置页面。
- 凭证保存于被排除提交的 `.local/model.json`，目录/文件权限分别为 0700/0600，状态接口不返回凭证。
- 配置后回到产品刷新即可读取本地配置；覆盖已有配置需要明确确认。
- `NODE_ENV=production` 时不加载本机模型配置，部署必须使用平台环境秘密。
- 配置完成后关闭该配置进程，不需要与产品长期一起运行。

不要在聊天、截图、命令行参数、工单或录屏里展示密钥。配置成功与真实调用成功是两项检查。

## 4. 生产环境配置

仅在平台 Secret/Environment 管理中输入真实值，不把凭证放在仓库、构建参数、前端变量或 URL。以下仅列变量名及用途，不提供凭证示例。

| 变量 | 用途与建议 |
| --- | --- |
| `NODE_ENV` | 正式部署设为 `production`，避免加载本机私有模型配置 |
| `HOST` | 容器/平台通常需监听 `0.0.0.0`，本机默认回环地址 |
| `PORT` | 使用平台分配端口；本地默认 4173 |
| `APP_ORIGIN` | 填实际产品的完整 HTTPS origin，含协议，不填路径；用于跨站来源校验 |
| `LLM_API_KEY` | 当前授权的模型凭证，只由服务端持有 |
| `LLM_BASE_URL` | 对应 OpenAI-compatible 服务地址；使用 DeepSeek 时按其官方接口文档配置 |
| `LLM_MODEL` | 该账号实际可用的模型标识；不要仅凭示例名猜测可用性 |
| `PUBLIC_DATA_ENABLED` | 仅精确为 `true` 才开放公开数据模式；未完成条款/可用性核对可关闭 |
| `FUYAO_API_KEY` | 可选扶摇凭证，不是 iFinD MCP 凭证；没有权益就不启用 |
| `IFIND_API_KEY` | 已集成 iFinD 适配器的服务端秘密配置；设置变量本身不证明该部署环境认证、额度或实际取数成功 |
| `IFIND_CONFIG_PATH` | 独立适配器可选的显式受保护文件路径，生产优先用 Secret；不要复制本机技能配置到镜像或仓库 |
| `REVIEW_USER` | 评审登录名，默认 reviewer |
| `REVIEW_PASSWORD` | 至少16字符；生产有模型/金融凭证时必须配置。浏览器原生登录弹窗验证后访问产品，不允许匿名消耗API额度 |

模型 key 与 model 同时存在时才启用模型模式。`/api/health` 的 `configured` 只代表配置存在，不代表凭证有效、额度充足或推理成功。

iFinD 已接通产品模式与数据分派，并完成本机正式 API 的全 12 股取数和筛选；精确字段、固定日期与调用预算见 [IFIND_DATA.md](IFIND_DATA.md)。营收/利润同比未确证累计口径，不能因响应有数值便开放该口径。部署后仍须复核健康能力、浏览器模式展示、权限与安全错误处理，不能用本机成功替代公网验收。

## 5. Node 或 Docker 部署步骤

### Node 单实例

1. 先按第 6 节完成仓库脱敏与授权，再连接该仓库。
2. 平台安装命令使用 `npm ci --omit=dev`，启动命令使用 `npm start`，设置 Node 20 或更高版本。
3. 在平台填写环境变量，设置单实例，不启用自动多副本扩容。
4. 健康检查路径设为 `/api/health`。外部 HTTPS origin 确定后填写 `APP_ORIGIN`，重启并检查浏览器 POST 请求。
5. 外部请求超时需容纳所启用数据适配器的合法请求耗时；不要仅因健康检查成功就判断完整数据链路可用。
6. 验证模型/数据出站 HTTPS、供应商限流和错误展示，再开放评委访问。

### Docker

仓库已提供 `Dockerfile`，使用 Node 22 Alpine、非 root 用户及静态文件白名单复制。**文档存在不代表镜像已完成实际构建/部署验证。**

```bash
docker build -t stock-lens .
docker run --rm -p 4173:4173 --env-file .env stock-lens
```

这是本机容器启动示例。生产建议由平台注入 Secrets，不分发 `.env` 文件；检查 Docker 构建上下文排除规则，确保私有文件未上传构建服务。镜像中不应包含 `.local/` 或技能配置。部署后从外网执行后续验收，不能仅在容器内 curl 成功就宣称公网可用。

### 最低限度运行保护

- 当前应用限流/并发上限为原型防护，不是账号级计费控制。反向代理用户可能共享同一 IP 限流桶，生产需边缘访问控制与预算保护。
- Origin 检查不是身份认证。应用已增加评审账号保护：生产配置模型或金融凭证却未设置至少16字符的 `REVIEW_PASSWORD` 时拒绝业务访问。账号仅通过笔试私有附件提供，部署需启用HTTPS。健康检查只返回配置状态，不返回凭证和金融数据。
- 首次发布、休眠唤醒和重启均检查快照失效提示；不以无限增加缓存时长掩盖状态问题。
- 仅记录必要的状态、延迟、错误代码，不记录认证头、私有响应或用户输入全文；上线前核对平台自动日志行为。
- 平台价格、免费额度、计费周期和服务条款由候选人在开通前确认，本文不承诺价格或免费运行。

## 8. 评审演示脚本（可选 60–180 秒）

演示前加载**合成数据**，不依赖收费调用即时响应；如果展示真实模型，应说明它与合成数据是两个独立维度。

### 60 秒版本

- **0–10秒**：说明“这是把研究意图变成可核对条件的原型，不预测涨跌；当前是虚构演示样本”。
- **10–25秒**：输入 `市盈率小于20`，展示草稿，确认后筛选。
- **25–45秒**：打开一条证据，说出实际值、来源/期间；解释未知不是不满足。
- **45–60秒**：将阈值改为 30，重新确认并展示同快照新增候选，强调这不是回测。

### 180 秒版本

在上述基础上增加：

- **60–100秒**：输入 `经营改善、估值合理、走势相对稳定`，展示五条建议及确认步骤；说明 25 和 30 是可调整起点，不是普遍投资标准。
- **100–125秒**：展示矛盾条件 `市盈率小于10且市盈率大于30`，说明系统不会偷偷改条件。
- **125–150秒**：展示保存/历史标识或一个缺失字段，解释数据与时间边界。
- **150–180秒**：用一句话说明 AI、引擎和数据适配器分工；说明 iFinD 本机正式 API 集成已验证但当前尚未公网部署，不以预录画面冒充已上线。

若现场真实调用失败，保留错误提示，解释可重试或手动定义；可以显式切换为演示流程，但不得将该结果说成真实调用成功。截图/录屏只选合成数据，除非已明确获得相应展示授权。
