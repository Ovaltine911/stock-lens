# 自动数据聚合适配

核验日期：2026-11-08。实现位置：`lib/auto-data.mjs`；无新增运行依赖。

## 接口与集成边界

```js
import { autoDataCapabilities, loadAutoSnapshot } from './lib/auto-data.mjs';

autoDataCapabilities(env); // { autoAvailable: boolean }，配置存在性，不是联网健康证明
const snapshot = await loadAutoSnapshot({ env, fetchImpl: fetch, now: () => Date.now() });
// mode: 'auto'；保留既有 Snapshot / Evidence 结构。
// optional supportedMetrics / providerSummary 仅描述本快照实际成功字段与来源。
```

- 仅使用 `RESEARCH_POOL` 的12家A股观察样本，不扩充样本、不宣称全市场。
- `FUYAO_API_KEY` 优先；缺失时只读取显式 `FUYAO_CONFIG_PATH` 的 JSON `FUYAO_API_KEY`。不搜索本机凭证，不把路径、凭证、远端自由文本写入证据或错误。配置读取仅在运行时发生。
- iFinD 使用已有 `IFIND_API_KEY` 或显式 `IFIND_CONFIG_PATH`（JSON `auth_token`）。备用适配动态导入现有严格解析器与客户端，以按字段/证券选择请求；不会调用 `loadIfindSnapshot` 全量重复查询。
- 模块不缓存；服务端协调者负责15分钟缓存与单飞请求。`now` 每次只取一次，供可重复测试和统一观察时刻使用。
- `asOf` 是成功核验的交易日历最后日期；`fetchedAt` 是读取开始时刻，两者不互相替代。逐字段日期独立保留。

## 正常主源请求预算

| 模块 | 请求 | 12股请求数 |
| --- | --- | ---: |
| 交易日历 | `calendar/trading-days`，最近100个自然日 | 1 |
| 估值 | `valuations/snapshot`，10+2分组 | 2 |
| 前复权日线 | `prices/historical-batch`，10+2分组，`interval=1d&adjust=forward` | 2 |
| 年度利润表 | `financials/income-statements-batch`，10+2分组，`period=annual&limit=2` | 2 |
| 加权ROE | `financials/indicators`，单股接口，12只各一次 | 12 |
| **合计** | 不含备用请求；不自动重试 | **19** |

主源共享信号量限制最多2个在途请求，覆盖响应正文读取。每批最多10股。每请求12秒超时覆盖连接及正文；禁止重定向。校验 HTTP 状态与 HTTP200下的 `code=0`，JSON正文上限2MiB。错误只输出中文说明与白名单错误码/安全数值状态码，不透传响应的 `message`、请求追踪字段或异常文本。数据边界递归去除密钥及编码形式的反射内容，之后才进入字段白名单。

交易日历、估值、日线、年度报表为必要模块：整模块请求都失败时返回错误（或明确的有限备用覆盖），不声称完整自动成功。单个批次失败时对应字段标记 `error`，保留其他批次并给出 warning。ROE是可选模块，单股失败不会阻止其他股票或主源字段。所有股票均无可核验字段时返回错误，不创建空成功快照。

## 字段与口径

所有展示单位、周期由 `catalog.getMetric()` 取得，不在适配中重定义目录。

| 目录指标 | 主源字段/计算 | 日期与边界 |
| --- | --- | --- |
| `pe_ttm` / `pb_mrq` | 估值原始有限数值，无量纲比率展示为倍 | `data.timestamp` 的上海日期；它是响应中上游元数据最大时点，不是逐字段交易日；缺失、未来或落后最近交易日则未知 |
| `volatility_20d` | 21个前复权收盘价，20个对数收益率样本标准差 × √252 ×100 | `date_ms` 按 `Asia/Shanghai` 转日期，末21日须与日历完全相同，样本方差分母19 |
| `return_20d` | `(末价 / 首价 - 1) ×100` | 与上述同一21日价格窗口 |
| `revenue_yoy_annual` | 相邻两年度 `operating_income` 原值计算增长百分比 | 两年须同证券、年度、完整年末、原币元、`CNY`；基年必须为正 |
| `profit_yoy_annual` | 相邻两年度 `parent_holder_net_profit` 原值计算增长百分比 | 非正基年时未知，不把扭亏包装成常规增速 |
| `roe` | 仅 `index_weighted_avg_roe`，保留源数值字符串，数值倍率1 | 使用最近已结束季度作为请求，须匹配响应证券及 `report`；缺失不猜前期；`asOf` 为报告期末而非公告日 |
| `revenue_yoy` / `profit_yoy` | **未知** | 累计/单季度语义未核验，不能把年度同比贴到这两个字段 |
| `market_cap` | **未知** | 接入端点无明确总市值金额字段，不猜测单位，不从行情倒推 |

### ROE单位已核验，不以数值大小猜测

2026-11-08读取的[官方财务指标文档](https://fuyao.aicubes.cn/docs/api-reference/financial-indicators/)明确：

> 百分比类指标按百分数值表达，例如89.12000000表示89.12%；名称含“收益率”的指标按百分比展示。

因此加权净资产收益率原始字符串直接转换为有限数值，不乘100；例如合成测试值0.125仍表示0.125%，不是12.5%。只接受准确字段，拒绝显式冲突单位、重复字段、非数字字符串；不采用扣非、摊薄或年化字段。报告元信息是接口回显，不被当成已证实首次披露时间。

### 年度和价格的审计证据

- 年度证据 `raw.records` 保留两年白名单原始记录：证券、年度、报告类型、年末毫秒戳、披露/修订毫秒戳、币种、营收与归母利润；附分子、分母、基年/当年、公式及原币元说明。缺少年度、非相邻年度、金额缺失、基年≤0、币种或单位冲突均未知。
- 相同披露时间可以是后续修订。日期不得晚于读取日；但即使合法，也不表示首次公告或历史时点可获得。年度同比不等同经营拐点，不用于无前视偏差回测。
- 日线拒绝重复/逆序日期、零值、负值、非有限价格、缺失交易日、陈旧末日及非前复权日线，不过滤坏值后偷偷拉长窗口。证据保存选中的21个日期与原始收盘价。
- 估值元数据实际可以发生在休市日。本次真实探测为11月8日元数据、日历最近交易日11月6日；适配保留这种差异并说明，绝不把元数据改贴为11月6日。

## 有限备用来源

只在扶摇某证券的 PE/PB/ROE不可用且 iFinD已显式配置时启动一次握手，随后仅查询缺失字段对应的证券组；不覆盖扶摇已有成功值，不补其他未经核验字段。

- 正常主源7类字段齐全时：**iFinD请求为零**。
- 单股仅缺ROE时：握手2次HTTP + 该单股财务工具1次，不取估值和其他11股。
- 全部主源不可用时：备用至多6次工具查询（每4股一组、两类），另有2次握手；仅已有适配的固定日期估值/ROE可能成功。
- 备用估值固定交易日2026-11-06、ROE固定报告期2026-09-30，不宣称实时或最新。已有主源交易日历时，备用估值只在日期一致时接纳；日期不同不拼成“同日估值”。
- 日历失败时不能确认最近交易日。若仅有备用数据，快照日期仅取已核验备用字段最大日期，warning明确这是有限固定日期覆盖，不是已核验最新交易日。
- 必要模块失败但日历已成功时保留日历日期；其他主源能力不伪装成功。备用失败且无主源可用快照则抛错。永不回退demo。

在主协调者既有4次受控探测基础上，本Worker额外发出**3次**已授权只读结构化请求：

| --- | --- | --- |
| 估值10只样本 | 200 / 0 | 返回10行，PE/PB各10个有限数值 |
| 估值其余2只样本 | 200 / 0 | 返回2行，PE/PB各2个有限数值 |
| 单只加权财务指标（另一只样本） | 200 / 0 | 报告2026-3，加权ROE为数值字符串 |

本次额外真实请求合计3，不升级付费、不交易、不打印密钥或真实股票指标数值；没有额外全量19次快照请求。

另对会话私有目录中既有响应进行**零网络请求**的实际解析回放，仅打印覆盖数量：

```text

volatilityUsable=2
annualGroups=2

annualProfitUsable=2

```

这证明当前解析器可消费已验证真实结构，不等于12只股票所有字段都经真实联网验收。真实覆盖已证实：估值12只；价格/年度2只；ROE既有1只加额外1只。全12股ROE/年度/价格的真实最新数据可用率、云端全量19次加载和接口长期稳定性仍由主协调者最终验收；不得把合成单测当成真实全量覆盖。
